Type passwords, MFA codes and CAPTCHA responses directly into the remote browser. Cookies are captured only when you choose Save session, and only through the gateway’s encrypted save flow. This page does not import saved sessions from local storage.

Alternative: Chrome extension relay

  1. In Chrome, open chrome://extensions and enable Developer mode.
  2. Choose Load unpacked and select the gateway repository’s extension folder.
  3. Open the extension, set its local gateway URL, and enter the one-time pairing code in the extension only.
  4. Select a provider and choose Review permissions & link; approve the requested access in Chrome.

The one-time code is issued by the gateway pairing flow; this page never displays or requests it.
