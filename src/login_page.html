Chat Gateway — Provider Login

How this works (relay login, no screenshots): the gateway's embedded browser has no screenshot or keyboard API, so you cannot see the provider page directly here. Instead this page shows the live URL, title, detected form fields and buttons, and a text snapshot — and you drive the page with relay actions (click, type, Enter, navigate) that the gateway executes inside the provider page. Complete the sign-in (including any SSO redirects — use Navigate if a step lands on a new URL), then press Complete to capture the session into sessions/<provider>.json for the normal send path.

Credentials: text relay is disabled by default; this page does not send text or passwords to the gateway. Use the browser extension to link an authenticated provider session. For trusted local development only, legacy typing can be explicitly enabled with CHAT_GATEWAY_LEGACY_LOGIN_RELAY=1; enabling it means text entered here reaches the gateway.

Honest limits: captchas, 2FA prompts, and SSO popups cannot be solved by the relay — you must complete those steps through the relay actions themselves (e.g. type the 2FA code into the code field when it appears), and some providers' bot checks may refuse synthetic input entirely. Sessions expire; when a provider reports session_expired, come back here and re-capture.
